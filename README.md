# fergetider-privacy

Personvernerklæringen for Fergetider på bokmål, engelsk, svensk, dansk, tysk, finsk og polsk.

GitHub Pages publiserer filene fra roten av `main` på https://cghove.github.io/fergetider-privacy/.
Åpne `index.html` lokalt for å forhåndsvise siden. Nettleserens språk velges på forsiden når det er tilgjengelig. Hver språkversjon har en egen adresse og lenker til alle de andre språkene.

Ved endringer i erklæringen, oppdater alle sju `privacy-*.html`-filer og bokmålsinnholdet i `index.html`. Kontroller datadeling, tillatelser, lokal lagring og eventuelle nye SDK-er mot appkoden før publisering.
